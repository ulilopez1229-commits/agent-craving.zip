# Agent Craving

Sistemas de inteligencia artificial de alto nivel.  
Estilo club privado. Acceso abierto. Ventaja no.

## Descripción

Agent Craving es un directorio selectivo de agentes y sistemas de IA que generan ventaja real.  
No es el más grande. Es el más curado.

## Estructura del proyecto

```
agent-craving/
├── public/
│   └── index.html          # Web principal
├── content/
│   └── newsletter/         # Borradores de Craving Weekly
├── docs/
│   ├── maintenance.md      # Sistema de mantenimiento
│   └── launch-plan.md      # Plan de lanzamiento
└── README.md
```

## Stack

- HTML + CSS puro (sin frameworks)
- Listo para desplegar en Vercel
- Diseño responsive y premium

## Despliegue en Vercel

1. Sube esta carpeta a un repositorio de GitHub
2. Conecta el repo en vercel.com
3. Root Directory: `public` (o deja la raíz si mueves el index.html)
4. Deploy
